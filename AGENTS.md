# Заметки для сопровождающих (людей и агентов)

Репозиторий собирает отчёты Казначейства об исполнении **консолидированных бюджетов
субъектов РФ** (ф. 0503317, 0503320, 0503321, 0503323; до 2005 г. — ф. 0524100) в DuckDB.
Федеральный бюджет — другой раздел портала и другой репозиторий (`roskazna-fb-execution`).

## Правила

* Запросы к roskazna.gov.ru — только последовательно, не чаще раза в 2 с, через
  `ROSKAZNA_PROXY` (портал отвечает только российским IP). Проверку TLS не отключать:
  сертификаты Минцифры лежат в `certs/`.
* Не обходить защиту портала (подмена браузерных заголовков, headless-браузеры).
* Сырые данные (`data/raw`, `data/db`, `data/export`) в git не коммитить; реестры
  `data/catalog/*.csv` — коммитить.
* Новый вариант макета — правка правил в `dims.py` / `layout.py` / `territory.py` /
  `chess.py` + тест в `tests/`. Не вводить «магические» номера граф: уровень бюджета
  и показатель определяются по тексту шапки.
* После изменений разбора: `python -m pytest`, `python -m roskazna_kbs build --force`
  (или `--years …`), `python scripts/coverage.py`, проверить раздел «Нераспознанные
  графы» в `docs/coverage.md`.
