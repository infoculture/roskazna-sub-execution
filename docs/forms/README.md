Годы в документации — годы **среза** (`report.report_date`, «на 1 число»). Срез на
1 января содержит итоги прошлого года: годовой отчёт «за 2025 год» имеет
`report_date = 2026-01-01`, `period_year = 2025`, `period_months = 12`.

Каждая форма составляется по каждой территории (≈ 83–91 субъект, г. Байконур) и
сводом по РФ: в БД свод всегда имеет код 95 (в файлах 2000–2005 гг. — `Mes0` / код 00);
свод есть за 2000–2005 гг. и с 2012 г. Коды территорий — внутренние коды Казначейства,
см. [../territories.md](../territories.md).

## Общее устройство книги формы

* **Шапка** (титул или верх первого листа): название формы, «на 1 …», наименование
  финансового органа и бюджета, периодичность, единица измерения, коды ОКУД, ОКПО, ОКТМО
  (ОКАТО в старых отчётах), ОКЕИ. Поля шапки — в таблице `report`.
* **Таблица раздела**: многоуровневая шапка с объединёнными ячейками, под ней — строка
  номеров граф (1, 2, 3 …). По этой строке разбор находит таблицу, а смысл графы
  (показатель, уровень бюджета) определяет по тексту шапки над ней (`src/roskazna_kbs/dims.py`).
  Исходный текст шапки каждой графы — `layout_column.header`.
* **Блоки.** Широкие таблицы печатаются двумя половинами: слева «Утверждено», справа
  «Исполнено» (`layout_column.block`). Продолжения таблицы на следующих печатных страницах
  наследуют макет.
* **Коды.** Кодовые графы (глава, КБК, Рз/Пр, ЦСР, ВР, КОСГУ) разнесены по полям
  `indicator`; «х» в кодовой графе — признак итоговой строки (`is_total_marker`).
