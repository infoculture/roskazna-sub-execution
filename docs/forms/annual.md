# Годовые формы: 0503320, 0503321, 0503323

Входят только в годовые пакеты (срез на 1 января, итоги прошлого года), по каждой
территории и своду по РФ (код 95, с итогов 2012 г.). Все суммы — рубли (ОКЕИ 383).
Широких витрин для этих форм нет: используйте `v_value` с фильтром по `form_code` и `section`.

| Форма | Отчётов | Даты среза | HTML | XLS / XLSX |
|---|---|---|---|---|
| 0503320 | 1 823 | 01.01.2006 – 01.01.2026 | 2006–2011 (`Mes_430y_<код>.html`) | 2012–2026 |
| 0503321 | 1 823 | 01.01.2006 – 01.01.2026 | 2006–2011 (`Mes_421y_<код>.html`) | 2012–2026 |
| 0503323 | 1 558 | 01.01.2009 – 01.01.2026 | 2009–2011 (`Mes_423y_<код>.html`) | 2012–2026 |

**Вид деятельности.** В срезах 01.01.2007 – 01.01.2013 (HTML и XLS) графы делятся ещё и
по видам деятельности: бюджетная, приносящая доход, итого — `value.activity` (`budget`,
`income_generating`, `total`). В остальные годы `activity` пуст.
При суммировании берите одну разбивку (обычно `activity = 'total'`), иначе значения
задвоятся.

## Ф. 0503320 — баланс исполнения

Баланс исполнения консолидированного бюджета субъекта РФ и бюджета ТГВФ.

| Раздел (`section`) | Лист (2012 → 2026) | Содержание |
|---|---|---|
| `balance` | `1` → `стр.1_14_Баланс` (2017) → `Баланс` (2018) → `стр.1_6 Баланс` (2019–2023) → `стр.1_8_Баланс` (2024–2026); HTML «1. Баланс исполнения бюджета» | актив (нефинансовые и финансовые активы) и пассив (обязательства, финансовый результат) |
| `offbalance` | `2` → `стр.15_20_Справка` → `Справка` → `стр.7_10_Справка` → `стр.9_12_Справка`; HTML «2. Справка» (только 2006) | справка о наличии имущества и обязательств на забалансовых счетах |
| `obligations` | `3` (2012–2013) → `стр.21_Таблица` → `Таблица` → `стр.11_Таблица` → `стр.13_Таблица` | справочная таблица по консолидируемым расчётам (строки 899–999 по бюджетам) |

* **Показатели:** `begin_balance` (на начало года), `end_balance` (на конец отчётного
  периода), `obligations` (таблица обязательств).
* **Коды:** строка баланса — `line_code` (010 … 700); в наименованиях — номера счетов
  («Основные средства (балансовая стоимость, 010100000)»). В справке номер забалансового
  счёта — `indicator.account_code` (01, 19, 30 …).
* **Особенности:**
  * в 2014–2016 гг. таблица обязательств напечатана на листе `2` вместе со справкой и
    попала в раздел `offbalance` (`measure = 'obligations'`, 259 отчётов);
  * справка 2006 г. (HTML) — «Справка по заключению счетов бюджетного учёта»: графы
    «Остаток на 1 января (до заключительных записей)» и «Заключительные записи по счёту …»
    по дебету и кредиту без уровней бюджета (`measure = 'amount'`, `budget_level = 'none'`).

```sql
-- Баланс свода по РФ на 01.01.2026: актив и пассив на начало и конец года, млрд руб.
SELECT line_code, name, measure, value / 1e9 AS bn
FROM v_value
WHERE form_code = '0503320' AND section = 'balance' AND is_preferred
  AND territory_code = '95' AND report_date = DATE '2026-01-01'
  AND budget_level = 'cons_subject_tgvf'
ORDER BY line_no, measure DESC;
```

## Ф. 0503321 — отчёт о финансовых результатах деятельности

Консолидированный отчёт о финансовых результатах деятельности (начисления, а не касса).

| Раздел (`section`) | Лист | Содержание |
|---|---|---|
| `results` | `1` (2012–2017) → `0503321` (2018–2019) → `0503321_1` (2020–2026); HTML «1. Отчет о финансовых результатах деятельности» | доходы (стр. 010), расходы (стр. 150), чистый операционный результат (стр. 300), операции с нефинансовыми и финансовыми активами и обязательствами (стр. 310–560) по КОСГУ |
| `results_changes` | `2` (2012–2017) → `Таблица` (2018–2019) → `0503321_2` (2020–2026) | изменение расчётов между бюджетами (строки 899–999 по бюджетам) |

* **Показатели:** в разделе `results` шапка не называет показатель — `measure = 'amount'`,
  графы — уровни бюджета; в `results_changes` — `inflow` (поступления) и, с 2020 г.,
  `income_change` / `expense_change` (доходы / расходы по изменению расчётов).
* **Коды:** код строки (`line_code`) + КОСГУ (`indicator.kosgu_code`). Одна строка формы
  может повторяться с разными КОСГУ (стр. 190 «Обслуживание долга» — 230, 231, 232, 234).
* **Особенность:** в шапке ф. 0503321 Республики Башкортостан указано «Федеральный
  бюджет» — ошибка заполнения в источнике; территория определяется по имени файла. То же
  встречается в шапках других отчётов 2024–2026 гг. (`territory_seen`, `source = 'report_header'`).

```sql
-- Чистый операционный результат (стр. 300) по территориям за 2025 г., млрд руб.
SELECT territory_code, territory_name, value / 1e9 AS bn
FROM v_value
WHERE form_code = '0503321' AND section = 'results' AND is_preferred
  AND report_date = DATE '2026-01-01' AND line_code = '300'
  AND budget_level = 'cons_subject_tgvf' AND coalesce(activity, 'total') = 'total'
ORDER BY value;
```

## Ф. 0503323 — отчёт о движении денежных средств

Консолидированный отчёт о движении денежных средств (с итогов 2008 г.).

| Раздел (`section`) | Лист | Содержание |
|---|---|---|
| `cash_flows` | `1`; HTML — три таблицы «1. Поступления», «2. Выбытия», «3. Изменение остатков средств» | поступления (стр. 0100), выбытия, изменение остатков по текущим, инвестиционным и финансовым операциям; КОСГУ |
| `cash_outflows_detail` | `2` | выбытия: строка «Расходы — всего» (стр. 9000, коды «x x»), затем КОСГУ × подраздел (`kosgu_code`, `rzpr_code`); сумма строк КОСГУ × подраздел равна итогу |

* **Показатели:** шапка не называет показатель — `measure = 'amount'`; графы — уровни
  бюджета (в HTML до 2011 г. — ещё `municipal_formations`, «бюджеты муниципальных
  образований», и вид деятельности).
* **Коды:** коды строк четырёхзначные (0100, 5030, 9000 …), КОСГУ — `kosgu_code`.
* **Особенность:** в 2012–2013 гг. на листе `2` — таблица поступлений по бюджетам
  (`measure = 'inflow'`, 169 отчётов), а не выбытия по разделам.

```sql
-- Кассовые выбытия по разделам классификации расходов, свод по РФ, 2025 г., млрд руб.
SELECT left(rzpr_code, 2) AS razdel, sum(value) / 1e9 AS bn
FROM v_value
WHERE form_code = '0503323' AND section = 'cash_outflows_detail' AND is_preferred
  AND territory_code = '95' AND report_date = DATE '2026-01-01'
  AND budget_level = 'cons_subject_tgvf' AND rzpr_code IS NOT NULL
GROUP BY 1 ORDER BY 1;
```
