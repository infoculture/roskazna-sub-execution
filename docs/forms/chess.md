# Книги «по графам» («шахматки»)

Сводные таблицы ф. 0503317, которые Казначейство публикует вместе с отчётами
территорий: одна книга = раздел формы × одна графа «Исполнено» (уровень бюджета).
Строки — Российская Федерация, федеральные округа и субъекты (по округам), колонки —
показатели формы (код строки + глава + КБК и наименование). Лист Excel вмещает ≈ 250
колонок, поэтому книга разбита на листы «1», «2», … по колонкам.

* **Где в данных:** `chess_value` (34,2 млн значений) и `chess_indicator` (38 тыс.
  показателей), витрина `v_chess`. Срезы 01.11.2005 – 01.09.2026; помесячно с 2006 г.
* **Что сохраняется:** только строки РФ (`territory_kind = 'country'`, `territory_code = '00'`)
  и федеральных округов (`territory_kind = 'okrug'`). Строки субъектов дублируют их
  собственные отчёты и не загружаются; состав округов на каждую дату — в
  `territory_seen` (`source = 'chess'`).
* **Показатель:** `measure = 'executed'`; уровень бюджета — по подписи над таблицей
  («Ф.428 Рз.1 Гр.14 … консолидированный бюджет субъекта РФ и бюджет ТГВФ»), графа —
  `graph` (до 2007 г. подграфы `1.1`, `1.2` записаны как `101`, `102`).
* **Зачем:** итоги по федеральным округам, которых нет в отчётах территорий, и итоги по
  РФ за 2005–2008 гг., когда сводного отчёта (код 95) нет. За 2009–2011 гг. итоговых
  колонок в БД нет (см. ниже) — итоги РФ этих лет считайте суммой субъектов.

## Файлы по годам

Годы — по срезу (М — месячный пакет, Г — годовой).

| Годы | Файлы |
|---|---|
| 2000–2005 | `Полная роспись отчета за <месяц> <год> … гр.N ….xls` — заполнены только строки субъектов, не разбираются |
| 2005 | `428 доходы гр.1 за декабрь 2005 года.xls` |
| 2006–2007 | RAR `отчет за <месяц> <год>.rar/428 за <месяц> <год> года доходы гр.1.1.xls`, `доходы/гр12.xls` |
| 2008–2011 (М) | RAR `<месяц> <год> доходы.rar/<месяц> <год> доходы 16 гр.xls`, `… доходы гр. 14.xls`, `Январь_2011_Доходы_группа_14.xls` |
| 2012–2014 (М) | `Доходы гр. 14.xls`, `Гр.14_0503317-3_ROSKAZNA.xls`, `14_0503317_на_01.03.2013.xls`, `1_23_0503317.xls`, `Д_гр.14_0503317.xls`, `14_0503317_М.xls` и др. |
| 2012 (Г) | RAR `Доходы.rar/Доходы/Гр.19_0503317_Y.xls` |
| 2012–2018 (М) | `0503317-3_ROSKAZNA_<раздел>_<графа>_<дата>.xls` |
| 2013 (Г) | `Доходы.zip/Доходы/14_0503317_Д.xls` (дата — по пакету) |
| 2014–2015 | `гр14_0503317_01012015.xls`, `гр.14_0503317_01072014_Д.xls` |
| 2016–2017 (Г) | `0503317-3_ROSKAZNA_1_17_01012017.xls` (BIFF) |
| 2018–2026 | `0503317-ROSKAZNA_<раздел>_<графа>_<ДДММГГГГ>.xls` — XLSX под расширением `.xls` |

Имена 2008–2016 гг. слишком разнообразны для шаблонов, поэтому книга без кода территории в
имени проверяется **по содержимому** (`chess.looks_like_chess`): строка показателей
(«код\nнаименование» или «000 100 … 010 ДОХОДЫ») и под ней строка «Российская Федерация» /
«Все источники». Раздел — по имени файла или папки, иначе по коду строки первого
показателя (010 — доходы, 200 — расходы, 5xx–8xx — источники); графа — из имени или подписи
«Ф.428 Рз.3 Гр.14»; дата — из имени, из «за <месяц> <год>» в пути или по пакету.

## Код показателя

`chess_indicator.indicator_code` — составной код как в шапке колонки:

| Годы | Вид | Пример |
|---|---|---|
| до 2013 г. | код строки + глава + КБК сегментами через пробел или слитно (23 знака) | `01000085000000000000000` — «Доходы — всего» |
| с 2013 г. | код строки + «***» + 17 знаков | `010 *** 85000000000000000` — «Доходы бюджета — ИТОГО» |

Разложение — в полях `line_code`, `admin_code`, `classification_code` (17 знаков). Итог
доходов — `line_code = '010' AND classification_code = '85000000000000000'`, итог
расходов — `'200'` / `'96000000000000000'`, результат исполнения — `'450'` /
`'79000000000000000'`, источники — `'500'` / `'90000000000000000'`.

## Федеральные округа

`chess_value.territory_code` для округов — **порядковый номер строки в книге**, а не
постоянный код. Нумерация менялась:

| Код | 11.2005 – 01.2012 | 04.2012 – 09.2026 |
|---|---|---|
| 1 | Центральный | Центральный |
| 2 | Северо-Западный | Северо-Западный |
| 3 | Южный | Южный |
| 4 | Приволжский | Северо-Кавказский |
| 5 | Уральский | Приволжский |
| 6 | Сибирский | Уральский |
| 7 | Дальневосточный | Сибирский |
| 8 | Северо-Кавказский (с 02.2010) | Дальневосточный |
| 9 | — | Крымский (04.2014 – 08.2016) |

Фильтруйте округа по `territory_name`. Состав округа менялся (Крымский ФО 2014–2016 гг.;
Бурятия и Забайкальский край перешли из Сибирского в Дальневосточный в 2018 г.) —
сравнивайте округа во времени с осторожностью.

## Известные особенности

* **2009–2011 гг. — неполные книги.** В БД из книг доходов и расходов этих лет загружено
  ≈ 700 показателей вместо ≈ 1 000–1 100 в соседних годах: нет итоговых колонок («Доходы —
  всего», «Расходы — всего») и налоговых доходов, максимум по РФ — безвозмездные
  поступления. Книг источников за эти годы нет. Причина не выяснена (вероятно, первые
  листы книг другого макета) — нужен разбор.
* **2014 г., четыре среза** (01.05, 01.06, 01.07, 01.12): у РФ в книгах доходов две строки
  уровня страны; вторая равна итогу Крымского ФО. Итог РФ = сумма двух строк (совпадает
  со сводом 95), `max(value)` даёт РФ без Крыма и Севастополя.
* **Пакет «На 1 апреля 2008»**: в нём книги `M3/отчет за март 2008.rar/март 2008 доходы
  … гр.xls`, но значения совпадают со срезом на 01.02.2008 — в БД они записаны на
  01.04.2008. Для этого среза берите сумму субъектов.
* Срез на 1 января приходит и в месячном, и в годовом пакете; `v_chess.is_preferred`
  выбирает годовой, затем более поздний пакет.
* С 2012 г. итоги РФ из «шахматок» совпадают со сводом по РФ (код 95) до рубля на всех
  срезах, кроме названных выше и двух мелких расхождений (01.06.2022 — 0,2 млн руб.,
  01.01.2024 — 73 млн руб.: «шахматка» собрана по месячному отчёту, свод — по годовому).
  Сверка — в [../coverage.md](../coverage.md).

## Примеры

```sql
-- Доходы консолидированных бюджетов субъектов (с ТГВФ) по федеральным округам, 01.09.2026, млрд руб.
SELECT territory_name, value / 1e9 AS bn
FROM v_chess
WHERE is_preferred AND section = 'income' AND report_date = DATE '2026-09-01'
  AND budget_level = 'cons_subject_tgvf'
  AND line_code = '010' AND classification_code = '85000000000000000'
ORDER BY territory_kind, value DESC;

-- Итог доходов РФ по срезам 2007–2008 гг. (свода 95 в эти годы нет)
SELECT report_date, value / 1e9 AS bn
FROM v_chess
WHERE is_preferred AND section = 'income' AND territory_code = '00'
  AND budget_level = 'cons_subject_tgvf'
  AND line_code = '010' AND classification_code = '85000000000000000'
  AND report_date BETWEEN DATE '2007-01-01' AND DATE '2008-12-01'
ORDER BY report_date;
```
