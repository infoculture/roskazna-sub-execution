# HTML-версии отчётов (`Mes*.html`)

Почти в каждом пакете есть HTML-версия отчётов по территориям — выгрузка из программного
комплекса Казначейства, кодировка CP1251. До 2011 г. HTML — **единственный** вариант
месячных отчётов (кроме годовых книг 2001–2004 гг.); с 2012 г. он дублирует Excel.

Годы — как в фильтре каталога: для годовых пакетов это отчётный год (срез на 1 января
следующего года). Внутренний номер формы в имени: 428 — 0503317, 430 — 0503320,
421 — 0503321, 423 — 0503323; суффикс `m` — месячный, `y` — годовой, `vy` — приносящая
доход деятельность. `<код>` — код территории Казначейства (`Mes0` / `Mes_428m_00` — свод,
в БД код 95).

## Устройство файла

* Абзацы `<p>` с наименованием территории, названием формы, «на ДД.ММ.ГГГГ» и
  «Единица измерения: руб.» (в 2000–2005 гг. — тыс. руб.; в 2007 г. единица не указана).
* Для каждого раздела — заголовок «Раздел: 1. Доходы» (2005–2011 гг.) или «1. Доходы
  бюджета» (с 2012 г.) и таблица: строка `<th>` с полными заголовками граф
  («Утвержденные бюджетные назначения: бюджет субъекта РФ»), далее строки `<td>`.
  Объединённых ячеек нет.
* В 2000–2006 гг. — одна таблица без разделов («Сводные показатели»,
  `section = 'summary'`): код, наименование и графы исполнения.

Разбор (`src/roskazna_kbs/htmlform.py`) превращает таблицу в «лист» — шапка, строка
номеров граф, строки данных — и передаёт её тому же коду, что и Excel
(`forms.parse_table`). Поэтому показатели, уровни бюджета и коды в HTML и Excel
одинаковы. Имя листа в `line.sheet_name` и `layout_column.sheet_name` — `html:<заголовок раздела>`.

## Особенности

* Заголовки граф — с опечатками и вариантами («Исполено», «На начало года, бюджетная
  деятельность»); их разбирает `htmlform._header_cell` и правила `dims.py`.
* Вид деятельности указан в заголовке графы («…, бюджетная деятельность») или в названии
  отчёта («внебюджетная деятельность») → `value.activity` / `report.activity`.
* Таблица с одним столбцом сумм без названия показателя (2000–2004 гг.) считается
  исполнением («Исполнено / …»).
* С 2012 г. HTML и Excel одного пакета совпадают по содержанию; HTML-отчёт берётся, только
  если Excel-книги в пакете нет или она не читается. Таких отчётов четыре: Чувашская
  Республика на 01.03.2013 (Excel-книга повреждена — обрезана таблица строк XLS) и свод по
  РФ на 01.02.2016, 01.09.2020, 01.06.2022.
* Исключение — своды 2013–2015 гг.: Excel-свод назван без кода территории
  (`95428r23.txt.xls`, `0503317 на 01.09.2013.xls`), поэтому HTML-свод того же пакета тоже
  загружен (14 отчётов, флаг `date_from_package`). `is_preferred` выбирает Excel.
