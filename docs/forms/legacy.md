# Ф. 0524100 — отчёты 2000–2004 гг.

До перехода на формы Инструкции № 191н отчёт об исполнении консолидированного бюджета
субъекта РФ составлялся по альбому форм 0524100 («форма 623»). В БД такие отчёты имеют
`form_code = '0524100'` — и месячные HTML-таблицы, и годовые книги XLS.

* **Где в данных:** 4 230 месячных отчётов (01.04.2000 – 01.12.2004; в 2000 г. — только
  квартальные срезы) и 449 годовых (итоги 2000–2004 гг., срезы 01.01.2001 – 01.01.2005).
  Отчёт на 01.01.2005 из месячного пакета — тоже 0524100.
* **Единица — тыс. руб.** Значения в БД умножены на 1000 (`report.unit_multiplier = 1000`,
  исходная единица — `unit_raw`). Где единица в файле не указана, она принята по умолчанию
  (флаг `unit_assumed_thousand`, 2 788 отчётов 2000–2003 гг.).
* **Уровни бюджета** — три: `cons_subject` (консолидированный бюджет субъекта, в т. ч.
  ЗАТО), `subject` (бюджет субъекта), `local_total` (местные бюджеты). Бюджетов ТГВФ в
  форме нет.
* **Классификация — старая** (Закон 1996 г. о бюджетной классификации): доходы — 7 знаков
  (`kbk_code`, «2064000»), расходы — функциональная классификация (раздел/подраздел,
  `rzpr_code`), целевая статья и вид расходов, экономическая классификация (ЭКР,
  `kosgu_code`); источники — 4–5 знаков. Прямого перехода к кодам 2005+ нет.

## Месячные отчёты: HTML (`section = 'summary'`)

Файлы `MM/Mes<код>.html` (`Mes0.html` — свод по РФ, в БД код 95), CP1251. Одна таблица:
код бюджетной классификации или код отчётности, наименование и три графы исполнения:

| Графа (текст шапки) | `measure` | `budget_level` |
|---|---|---|
| «Кассовое исполнение консолидированного бюджета субъекта РФ (ЗАТО) всего», «Исполнено / Консолидированный бюджет субъекта РФ» | `executed` | `cons_subject` |
| «Кассовое исполнение субъекта РФ», «Исполнено / Бюджет субъекта РФ» | `executed` | `subject` |
| «Кассовое исполнение местных бюджетов (ЗАТО)», «Исполнено / Местные бюджеты» | `executed` | `local_total` |

Доходы, расходы и источники идут подряд одной таблицей; раздел строки определяется по
коду. Утверждённых назначений в месячных HTML нет. Подробно о HTML-версиях — [html.md](html.md).

## Годовые отчёты: XLS

Книга `002<код>.xls` (`002001.xls` — Республика Башкортостан), свод —
`Свод <год> форма 623.xls` или `002000.xls`. Итоги 2000 г. — только HTML (`Mes0`…`Mes94`).

| Лист | Раздел (`section`) | Содержание |
|---|---|---|
| `Titul` / `Титул` | — | титул: территория, дата, единица |
| `Doxod` / `Доходы` | `income` | доходы по 7-значным кодам |
| `Ras-ot` / `Функциональная структура` | `expense` | расходы по разделам и подразделам функциональной классификации |
| `Fin` / `Источники финансирования` | `sources` | источники финансирования дефицита |
| `R-01-ot` … `R-96-ot` / `01` … `30` | `expense_detail` | расходы внутри раздела: подраздел + целевая статья + вид расходов + ЭКР |

Графы годовой книги:

| Графа | `measure` | `budget_level` |
|---|---|---|
| «Утвержденные бюджетные назначения / консолидированный бюджет субъекта», «Утверждено на год …» | `approved` | `cons_subject` (`subject`, `local_total` — где есть) |
| «Исполнено всего», «Кассовые расходы бюджетных средств всего» | `executed` | `cons_subject` |
| «в т. ч. по бюджету субъекта», «Кассовые расходы средств бюджета субъекта РФ» | `executed` | `subject` |
| «по местным бюджетам», «Кассовые расходы средств местных бюджетов» | `executed` | `local_total` |

Шапка таблицы в книгах 2001–2004 гг. «нарезана» по строкам и с разрядкой («И с п о л н е н о»);
модуль `legacy.py` собирает её в канонические заголовки.

## Особенности

* `Полная роспись отчета за <месяц> <год> … гр.N ….xls` (2000–2005 гг.) — роспись по
  графам, в которой заполнены только строки субъектов; не разбирается
  (`archive_member.content_kind = 'other'`). Итоги по РФ есть в сводном HTML.
* В пакете за 01.03.2002 книги `Февраль 2002 Графа 7/8/9 (без ЗАТО).xls` — без таблицы
  формы и кода территории: в БД три пустых отчёта (`n_lines = 0`, флаги
  `no_table:Доходы;no_territory_code`).
* Свод за 2003 г. (`Свод 2003 форма 623.xls`) без даты в шапке — дата взята по пакету
  (`date_from_package`).
* В 89 годовых книгах за 2001 г. лист `R-09-ot` без таблицы (флаг `no_table:R-09-ot`).
* Наименования территорий в шапках этих лет — с заглавными буквами в каждом слове
  («Красноярский Край»); для анализа берите `territory.name` или `territory_seen`.

* Итогов доходов два: «ИТОГО ДОХОДОВ» (код 8500000) и «ВСЕГО ДОХОДОВ» (8900000, больше
  первого на 350–460 млрд руб. в своде за 2003–2004 гг.). В HTML-таблицах коды итогов не
  напечатаны — ищите строку по наименованию.

```sql
-- «Всего доходов» консолидированных бюджетов субъектов, свод по РФ, итоги 2000–2004 гг., млрд руб.
SELECT r.period_year, r.member_path, v.value / 1e9 AS income_bn
FROM v_value v JOIN v_report r USING (report_id)
WHERE r.form_code = '0524100' AND r.period_months = 12 AND r.territory_code = '95' AND r.is_preferred
  AND v.measure = 'executed' AND v.budget_level = 'cons_subject' AND v.name = 'ВСЕГО ДОХОДОВ'
ORDER BY 1;
```
