# Коды территорий

Отчёты и «шахматки» Казначейства используют **внутренний двузначный код территории**.
Он не совпадает ни с ОКАТО/ОКТМО, ни с конституционной нумерацией субъектов, ни с кодами
ГИБДД. В БД это `report.territory_code` и `territory.territory_code`.

* Код берётся из имени книги (`01_01.09.2026_0503317.XLS`, `0503317-3_FO_015-….XLS`,
  `Mes_428m_01.html`). Для книг без кода в имени (МОУ ФК 2013–2015 гг.) — по
  наименованию в шапке (флаг `territory_from_header`).
* Наименования — из `TerrList_428m.html`, «шахматок» и шапок отчётов. Все встреченные пары
  «код → наименование» по датам и источникам — в `territory_seen`; в `territory.name` —
  последнее наименование.
* **95** — сводный отчёт по РФ (в файлах 2000–2005 гг. — `Mes0` / код 00).
* В «шахматках» код РФ — `00`, коды федеральных округов — порядковые номера строк
  (см. [forms/chess.md](forms/chess.md#федеральные-округа)).

## Коды переиспользуются

После объединения субъектов освободившиеся коды Казначейство отдало новым территориям.
`territory.name` показывает только последнее наименование, поэтому при анализе по годам
берите наименование на дату отчёта из `territory_seen` или ограничивайте период:

| Код | Было | Срезы | Стало | Срезы |
|---|---|---|---|---|
| 70 | Читинская область | 04.2000 – 01.2009 | Запорожская область | с 04.2023 |
| 81 | Агинский Бурятский АО | 04.2000 – 01.2009 | Федеральная территория «Сириус» | с 04.2022 |
| 82 | Коми-Пермяцкий АО | 04.2000 – 01.2007 | Донецкая Народная Республика | с 04.2023 |
| 83 | Корякский АО | 04.2000 – 01.2008 | Луганская Народная Республика | с 04.2023 |

```sql
-- Наименование территории на дату отчёта
SELECT r.report_id, r.report_date, r.territory_code, s.territory_name
FROM report r
ASOF JOIN (SELECT DISTINCT territory_code, report_date, territory_name
           FROM territory_seen WHERE source = 'terrlist') s
  ON s.territory_code = r.territory_code AND s.report_date <= r.report_date
WHERE r.territory_code = '70' AND r.form_code = '0503317'
ORDER BY r.report_date;
```
